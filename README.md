# DroneDelight

Full-stack application for the DroneDelight project.

## Structure

- `client/` — frontend (Vite + React)
- `server/` — backend (Node.js/Express)

## Getting started

Install and run each part independently:

```bash
# client
cd client
npm install
npm run dev

# server
cd server
npm install
npm start
```

Copy `example.env` to `.env` in each directory and adjust the values as needed.
